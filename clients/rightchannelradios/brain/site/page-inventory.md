# Right Channel Radios: pages and CRO tests

- Same-day shipping cutoff noon Mountain Standard Time, Monday to Friday; later Friday and weekend orders ship Monday (call 2026-11-24).
- No guaranteed arrival dates; keep same-day shipping urgency and realistic delivery ranges (call 2026-11-24).
- Recommendations for a radio include an antenna and coax, mounts where needed; exclude redundant SWR meters (call 2026-11-24).
- Comparison content sits below description and specs; match radio size; favour popular, reviewed products (call 2026-11-24).
- Comparison data is static, built from size and review counts; recency weighting not implemented (call 2026-11-24).
- Shopify CRO preview requires the `view=CRO` parameter; native preview access to be fixed (call 2026-11-24).
