## Facts stated
- Three integration options exist to capture vehicle data for external systems: injecting the Convermax component into a custom popup through a CSS selector; using the Convermax NPM package to pull fitment data into a custom front end; and calling the Convermax API by reading the vehicle parameters in the network URL (call 2026-07-23).
- The Convermax JS API exposes a function to get the current vehicle, and events that fire when the vehicle changes; it can force the vehicle popup and read the selection from browser storage (call 2026-07-23).
- Email integrations are supported, with Klaviyo as the example shown; other platforms can be added on request (call 2026-07-23).
- Vehicle data is written to the Shopify order "additional details" field, and to selected-vehicle and garage meta fields on customer profiles (call 2026-07-23).
- The selected vehicle is sometimes missing from customer meta fields, though present on some orders; Convermax cannot fully troubleshoot without read access to customer and order data (call 2026-07-23).
- The target vehicle capture rate is 20%, with 5% an acceptable baseline (call 2026-07-23).
- Email integration is being built with Queen One; Convermax will integrate with Queen One or other platforms when requested (call 2026-07-23).
